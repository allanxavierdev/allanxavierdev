# 👨‍💻 Allan Xavier



Sou desenvolvedor full stack, formado em Ciência da Computação. Construo sistemas do banco de dados até a interface: APIs em Python e TypeScript, front em React e apps mobile em Flutter.

Fundei a **[Oryn Tecnologia](https://www.orynai.com.br/)**, onde desenvolvo software e automações com IA para pequenas e médias empresas, do levantamento de requisitos ao deploy. Também criei o **[AnatomIA](https://www.getanatomia.com/)**, um app de estudo para estudantes de medicina.

Gosto de PostgreSQL bem modelado, isolamento de dados por cliente com Row Level Security e código coberto por testes.

---

## 🚀 O que estou construindo

- **AnatomIA**: app em Flutter de flashcards de anatomia com repetição espaçada (SM-2), backend em Supabase/PostgreSQL, Edge Functions com IA (Claude API) e site com checkout em Next.js
- **CRM para gráficas**: SaaS multi-tenant em Next.js 16, Drizzle ORM e PostgreSQL com RLS, com qualificação de leads por LLM e testes em Vitest e Playwright
- **Atendimento no WhatsApp com controle por cargo**: sistema em Next.js e PostgreSQL integrado à WhatsApp Cloud API, com criptografia, log de acesso para a LGPD e deploy com Docker e Nginx
- **CRM multi-tenant** em React 19, TanStack Query, Zustand e Supabase, com Kanban, dashboards e triagem de leads por IA
- **Sistema de gestão escolar**: API REST em FastAPI e Django com PostgreSQL e JWT, em produção desde 2025
- **[AI Knowledge Assistant](https://github.com/allanxavierdev/ai-knowledge-assistant)**: pipeline RAG em FastAPI para perguntas sobre documentos privados

## 🛠️ Experiência Técnica

- APIs REST com **FastAPI**, **Django** e **Next.js**
- Modelagem de dados com **PostgreSQL**: migrations, índices, funções e **Row Level Security** multi-tenant
- Front-end com **React 19**, **TypeScript**, **TanStack Query**, **Zustand** e **Tailwind CSS**
- Apps mobile com **Flutter** e **Riverpod**, com dados offline e sincronização
- Backend serverless com **Supabase** (Auth, Edge Functions, Realtime)
- Testes automatizados com **Vitest**, **Playwright** e **flutter test**
- Containerização com **Docker**, **Nginx** e deploy na **Vercel**, **AWS** e VPS
- Webhooks, pagamentos e integração com APIs externas
- Monitoramento com **Sentry** e analytics com **PostHog**
